## 当前源码行为（不是实体接线确认）

下表由 `SF6/Board/board_io.c` 的 `ReadInputs()`、`SF6/Core/input_bindings.h` 和 `SF6/Core/controller_logic.c` 的 `Logic_Process()` 推导。实体按钮与引脚的对应关系不能仅凭源码确定。

| 输入引脚 | 当前源码用途 |
| --- | --- |
| PB1 / PB3 | 下 / 右 |
| PB4～PB9 | LP、MP、HP、LK、MK、HK 六个拳脚输入 |
| PB10（IN_SUPER） | 左方向，同时参与宏动作分支选择 |
| PB11（IN_SP1） | 舞必杀：松开普通版，按住时新按 LK 选 OD，花蝶扇可新按 MK 蓄力 |
| PB12（IN_SP2） | 上方向 |
| PB14（IN_SP4） | 旧镜像功能停用，未分配新功能 |
| PB15（IN_X） | 原抓投键，现按下沿换边或触发 SUPER |
| PA10（IN_COMBO1） | 中拳＋中脚 |
| PB0、PB2、PB13、PA11、PA12 | 当前读取但没有对应有效输出用途 |
| PA13 | 当前未实现 LA1 输入读取 |

源码结构保留 `GPIO_Init_All()` → `ReadInputs()` → `Logic_Process(in)` → `Output_Update(out)`，由 SysTick 节拍驱动；目标 72 MHz 下约 60 FPS，PA0～PA9 为开漏输出。

当前实现细节：

- `QUEUE_LEN = 4`，环形队列最多等待三个动作，另有一个当前执行动作。
- `MAX_FRAMES = 4`，普通 SP 动作分支为四帧；SUPER 实际执行八帧。
- 必杀键现启用舞配置，普通/OD 均为四帧，扇子蓄力在四帧前缀后进入非阻塞保持阶段。旧 SP 和 HOLD 表保留但没有按键触发，`HOLD_THRESHOLD = 10` 保留，不用于本次蓄力。
- 普通宏及扇子前三帧方向独占输出；扇子自动轻拳阶段恢复普通输入，只消耗已接受的修饰键到松开。保持时暂停后续宏，MK 松开恢复队列；不强制释放用户自己按住的轻拳。SUPER 入队时记录朝向，必杀按下准备时锁定选招和朝向，之后变化不影响本次动作。
- 上电 `facing_left = 0`（朝右）。SUPER 键按下沿：四方向全松则切换朝向且不入队；有下、左、右则按下优先、其次左、右选招；只有上不执行。方向可先按或与功能键同次采样出现，先按功能键再补方向不会触发。
- SUPER 无方向的旧八帧空表仍保留供历史动作对照，但按键入口已改为换边，不再触发该空表。普通移动不镜像，轻拳+轻脚可手动抓投。

当前固定选择 `SF6/Profiles/mai_profile.c`，舞普通/OD/蓄力数据独立保存；`SF6/Profiles/current_profile.c` 原表不变，舞配置的 SUPER 继续引用原八帧表。结构见 [代码结构与扩展指南](代码结构与扩展指南.md)，本次按键规则、逐帧表和边界见 [舞必杀与扇子蓄力](舞必杀与扇子蓄力.md)。未启用角色切换，未烧录。用户对旧固件可正常使用的确认仍有效，不代表已确认这次新功能。

2026-10-16 源码规则：必杀按下时按实体方向选择，无方向轻扇、下重升龙、左轻龙炎舞、右轻忍蜂，下优先于左、右，只有上不准备。按住只准备，松开普通；仍按住时 LK 新按下提交 OD，仅花蝶扇可由 MK 新按下提交普通蓄力。预先按住的修饰键需松开再按；同帧 LK/MK 以 OD 优先，必杀松开同帧以普通优先。每轮只提交一次，队列满丢弃且不补发。蓄力请求编号相互独立；早松或排队期间松 MK 仍完成轻扇，至少输出一帧轻拳，不补满 19 帧。

2026-10-16 软件验证：Keil 完整编译 0 错误、0 警告；旧行为对照、新必杀/OD/蓄力回归及 GPIO/SysTick 模型通过。**未烧录、待实机确认**。待实机验收：短按与长按 MK、满蓄是否自动释放、游戏输入缓冲及普通松键手感；软件采样/输出帧数不等于游戏确认帧数，不承诺松 MK 即刻发扇。

当前 SUPER 逐帧输出（源码推导，默认朝右，末帧全部松开）：

| 按下 SUPER 时的方向选择 | 第 1～8 帧 |
| --- | --- |
| 下（含下左、下右） | 下 → 下左 → 左 → 下 → 下左 → 左 → 重拳 → 松开 |
| 左（没有下） | 下 → 下右 → 右 → 下 → 下右 → 右 → 重脚 → 松开 |
| 右（没有下、左） | 下 → 下右 → 右 → 下 → 下右 → 右 → 重拳 → 松开 |

记忆朝向为左时，仅交换表中左右方向；选择分支仍使用实体方向，未改成相对前后。每次按下固定动作和朝向，松开方向或之后切换朝向均不改变已入队的动作。
