## 输入记法

以下统一按**角色面向右侧**书写；换边时左右镜像，拳脚不变。

```text
7 ↖ 后上    8 ↑ 上    9 ↗ 前上
4 ← 后      5 中立    6 → 前
1 ↙ 后下    2 ↓ 下    3 ↘ 前下
```

| 记号 | 含义 |
| --- | --- |
| LP / MP / HP | 轻拳 / 中拳 / 重拳 |
| LK / MK / HK | 轻脚 / 中脚 / 重脚 |
| P / K | 任意一种拳 / 脚；指定强度时依指定键 |
| PP / KK | 两个不同拳键 / 脚键同时按 |
| PPP / KKK | 三个拳键 / 脚键同时按 |
| + | 同时输入方向与按键，或同时按多个键 |
| 逗号 | 按先后顺序输入；不是同时按 |
| / | 可选输入，如 LP/MP 表示轻拳或中拳 |
| n | 中立，不输入方向 |
| 蓄 | 先保持前一个方向再切换；所需时长随招式/版本确认 |
| 可蓄 / 长按 | 保持攻击键；与方向蓄力不是一回事 |
| ┣ / ┗ | 上方母招或姿态的派生；不是独立起手 |
| JF | 精准输入时机，需在训练模式确认 |
| Lv.1 / Lv.2 / Lv.3 | SA 等级，分别消耗 1 / 2 / 3 格超必杀槽 |
| CA | 低血量强化超必杀；通常为体力不高于 25% 时强化 SA3 |
| OD可用 | 表中指令是普通版；OD 一般把 P/K 换成 PP/KK，特殊例外另注 |
| OD限定 | 该招只在 OD 或指定 OD 派生条件下成立 |

常见输入：236＝↓↘→，214＝↓↙←，623＝→↓↘，63214＝→↘↓↙←；方向一周/两周表示 360°/720° 类输入。本表不把它们改写成可能不通用的简化摇杆指令。

**注意 OD 标记：** 招式名前的“OD可用”不是要求每次都按双键。桑吉尔夫双截旋风掌普通版为 PP，OD 版为 PPP。派生表中的 OD 条件、姿态、醉意、库存、空中和近身条件均必须一起满足。

## 共通操作

| 动作 | 经典输入 |
| --- | --- |
| 站立普通攻击 | 中立 + LP / MP / HP / LK / MK / HK |
| 蹲姿普通攻击 | ↓ + 对应拳脚 |
| 跳跃普通攻击 | 跳跃中按对应拳脚；角色可能有方向或跳跃方式限定 |
| 前进 / 后退 | → / ← |
| 前冲 / 后撤 | →→ / ←←（66 / 44） |
| 普通投 / 拆投 | 近身 LP+LK；前后投及角色额外投见分表 |
| 斗气迸放（Drive Impact） | HP+HK |
| 斗气招架（Drive Parry） | MP+MK |
| 招架冲锋（Parry Drive Rush） | 招架中 →→ |
| 取消冲锋（Cancel Drive Rush） | 可取消普通技中 →→，或符合条件时 MP+MK |
| 斗气反攻（Drive Reversal） | 防御中 →+HP+HK；起身版本需符合起身窗口 |

本文件只供查招；不会改变手柄工程。游戏指令并不等于现有宏已经支持：蓄力、空中、长按、360°/720°、多次派生须另行验证，不能直接压进固定四帧输出。
