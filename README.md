# STM32 街霸宏手柄工程

基于 STM32F103C8T6 的格斗手柄宏控制项目，使用 Keil MDK 和 ARM Compiler 5。
单片机读取低电平有效的机械按键，通过 PA0～PA9 开漏输出模拟手柄按键。

## 打开工程

使用 Keil µVision 打开 `SF6/STREETFIGHT6.uvprojx`。
迁移后的工程配置使用 ARM Compiler 5.06 update 5（build 528）、ARM.CMSIS 4.5.0 和 Keil.STM32F1xx_DFP 2.4.1。工程已固定两个支持包的版本；新电脑需先安装上述依赖。CMSIS 6 不支持 ARM Compiler 5，不要将该工程的 CMSIS 自动升级到 6.x。

源码时钟配置以外部 8 MHz 晶振为基础，目标主频为 72 MHz。
在该主频下，SysTick 周期约为 16.7 ms。
保留长度为 4 的动作队列、`MAX_FRAMES = 4` 和 `HOLD_THRESHOLD = 10`。

### 2026-10-15 超必杀与换边

- 原抓投键现为超必杀/换边键：上下左右全松时点按切换朝向；先按住下、左或右再点按，选择原有超必杀。同一次采样同时按下也可触发，不强制提前一帧。
- 上电默认朝右。只有上方向时不执行；按住功能键后再补方向不触发，必须松开功能键再按。斜方向沿用下优先，其次左、右。
- 每次按下只执行一次；动作触发时锁定朝向，之后换边不影响正在播放或排队中的动作。普通方向不镜像。
- 原超必杀键为必杀预留键，用户要求先占位，尚未指定招式；按下不输出动作。原独立镜像键停用。抓投仍可用轻拳+轻脚。
- SUPER 保留八帧原表，普通 SP 表及四帧长度未改，GPIO、帧率和队列长度未改。新固件需经用户实际使用验证，未进行烧录。
- 本次验证：Keil 完整重编译 0 错误、0 警告；便携 TinyCC 运行 849,635 帧保留行为对照及新增换边/触发/队列朝向测试通过，GPIO 和 SysTick 模型检查通过。
